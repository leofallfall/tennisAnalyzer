# Testing Strategy

## Commands

```bash
./scripts/check.sh            # everything (lint, format, types, contracts, tests)
uv run pytest                 # Python tests
uv run pytest -m "not slow"   # skip real-model tests
pnpm -r test                  # Vitest
```

## Unit tests (`tests/unit`, `apps/web/src/**/*.test.ts`)

- Metadata parsing from ffprobe JSON (rotation conventions, VFR, missing fields).
- Validation rules (errors vs warnings).
- Quality metrics on synthetic images (sharp vs blurred, dark, clipped).
- Geometry: projected angles, pixel aspect handling, non-observable outcomes.
- Contracts: `Measurement` refuses values when not observable; JSON Schemas up to date.
- Unimplemented modules raise `NotYetImplementedError` (no fake output).
- Web: frame/time conversion round-trips for 24–240 fps, pose lookup never substitutes
  neighbours, letterbox geometry, formatting.

## Integration tests (`tests/integration`, web page tests)

- API: upload → metadata; rejects bad extension / non-video / too-low resolution with
  structured errors; analysis lifecycle created → queued → completed via the worker;
  restart rules (409); failed job surfaces `error.code`; artifacts served.
- Pipeline with the real MediaPipe model (`requires_model`, `slow`): outputs, timestamps,
  stride, overlay.
- Web pages with mocked `fetch`: navigation, mode selection, multi-video relation
  required, placeholders are labelled, errors displayed.

## Computer vision tests

- **Synthetic data** (generated by FFmpeg at test time): rotation, VFR, sizes, frame
  rates, corrupt files. A test pattern contains no person → expected result is
  *not observable* (guards against hallucinated poses).
- **Self-identifying frames** (M1.10, `tests/unit/test_timemap.py`): each synthetic frame
  carries its own index as black/white blocks; decoding the real proxy gives ground truth
  for the proxy → original time map (CFR, VFR, non-zero start, early audio, 120/240 fps).
  Synthetic only: not a substitute for real-footage validation (M1.11).
- **Golden pose files** (future): small real clips with stored expected keypoints;
  tolerance-based comparison to detect regressions when upgrading models.
- **Annotated validation set** (future, not in CI): manually labelled joints at key
  frames, phase boundaries and stroke types, used to compute per-metric error.

## Video fixtures

See `tests/fixtures/README.md`. Real footage lives in `tests/fixtures/real/`
(git-ignored) with a manifest describing conditions. Only footage the owner has rights
to; never broadcast footage.

## Real-world amateur video testing (M1 acceptance)

Matrix to cover: camera position (side, behind, diagonal, front), height (hand-held,
tripod at waist, fence-mounted), fps (30/60/120/240), orientation, lighting (sun, shade,
indoor, evening), player distance (half court, full court), handedness, clothing contrast.
For each clip record: detection rate, visually inspected wrist/elbow accuracy in the
forward swing, processing time per frame, quality ratings vs human judgement.

## Acceptance criteria for "works"

A feature is "working" only when an automated test or a documented manual check on real
footage demonstrates it. Claims in docs/commits must match test evidence.
